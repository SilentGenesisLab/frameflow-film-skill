Frameflow Film Skill

把一段产品描述做成一条可投放的广告短片：分镜、分段生成、拼接、配乐、配音、混剪、调色、终检，最后输出 MP4。这份说明面向第一次使用的协作者。

先记住两条
  • 下单和分镜不花钱；只有人在网页里点了确认，才开始调用付费模型。
  • 审批只能由人类登录网页完成。Agent Key 调审批固定 403，这不是故障。

1. 下载

需要 Python 3.8 以上，脚本只用标准库，不用安装依赖。

git clone https://github.com/SilentGenesisLab/frameflow-film-skill.git
cd frameflow-film-skill/frameflow-film

不方便用 git 就下载打包版： frameflow-film-skill.zip。

装成 Claude Code Skill（可选）

mkdir -p ~/.claude/skills
cp -r frameflow-film ~/.claude/skills/

之后在 Claude Code 里说「用 Frameflow 出一条产品片」即可触发。

2. 准备账号和 Key

  1. 打开 aivideo.sligenai.cn 注册或登录。任务按团队隔离。
  2. 想共用产品图和积分，就让管理员用团队邀请把你加进去。自己注册会新建空团队，默认 0 积分，出片会返回 402。
  3. 在团队/账号页创建「Agent 访问密钥」，勾选 read + write + generate。Key 只显示一次，不要发群里或提交仓库。
  4. 准备至少 1 张、最多 3 张公网可读的 https 直链参考图。没有直链就先上传到平台产品库，下单时用 --product-id 或 --conversation-id。

3. 写入凭据并自检

python scripts/film.py setup
python scripts/film.py doctor

setup 会交互询问平台地址和 Key，写到 ~/.config/aivideo/credentials（权限 600），不会进 shell 历史。也可以改用环境变量：

export AIVIDEO_BASE_URL=https://aivideo.sligenai.cn
export AIVIDEO_API_KEY=你的Key

doctor 会打印团队、Key 类型和 scopes。看到 can_create: true 就能下单；缺 scope 回平台补权限。

显示 type: agent 是正常的：Agent Key 负责下单和查进度，审批由人完成。

4. 出一条片

写 brief

写清四件事，别的都是噪音：产品是什么、给谁用、必须出现哪些画面、一句说结果的卖点。不要写参数、认证、销量、疗效，分镜模型会照抄。

晨研 Mini 是给通勤族用的便携咖啡机，30 秒出浓缩。
要拍出按键、出液、手表计时、端着走的画面，强调小和快。

下单

python scripts/film.py create \
  --brief-file brief.txt \
  --title "晨研 Mini 产品片" \
  --product "晨研 Mini" \
  --seconds 30 --ratio 9:16 \
  --ref https://example.com/pack.jpg

返回里的 id（UUID）才是平台任务 ID；pipelineJobId 是流水线内部编号，别拿来查状态。

等人批准

python scripts/film.py status <平台任务ID>

planning 表示分镜还没出完；awaiting_approval 或 pending_approval 都表示在等人批。批准入口：登录平台 →「创作搭档」→ 待确认卡片 → 确认。

跟踪到成片

python scripts/film.py watch <平台任务ID> --interval 30 --timeout 5400

到 delivered / failed / rejected 自动停止。进度看 units_done / unit_count，成片看 result_url，合格与否看 qc.passed。

5. 费用

阶段是否计费
下单、分镜、等待审批0 元
批准之后按生成单元计费，40 秒片约 3 个单元

402 = 个人积分不足，停下别重试，让管理员分配后再提交。

6. 常见错误

码含义与处理
401Key 无效或没配置，重新跑 setup 和 doctor
402积分不足，找管理员分配
403scope 不足，或试图用 Agent Key 审批
404任务不存在，或不属于当前团队
409任务已处置，先查最新状态
422参数不合法，最常见是缺参考图
503平台流水线未配置，联系管理员

7. 限制

  • 成片 720p、24 fps。
  • 配乐由 Suno 自动生成，配音为固定音色。
  • 没有配乐时会跳过后期重剪，直接交付拼接片，此时 qc.applied = false。
  • 只从零生成画面，不复用实拍素材。
